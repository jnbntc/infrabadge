## Tamaño y seguridad

Candidato local: **904512B**,144064B libres en slot1MiB (13,74%). +19136B respecto
del firmware físico M3.5 y+19072B respecto de su cierre software. Misma tabla,
bootloader y target ESP32-S3/8MB. Sin OTA, Secure Boot, Flash Encryption o PSRAM.
IRAM dedicada16384B; DIRAM compartida aproximadamente168499/341760B (datos20380,
BSS66256, código81863); no equivale al mínimo heap durante TLS/provisión.
RTC6184B UI +32B política=6216B, aserción conjunta<=7680. La configuración/USB
sólo usa memoria normal; no replica credenciales en RTC. Ver
[manifiesto local](m36-build-manifest.json) para SHA y valores de la compilación
congelada; identificador embebido de Git/metadata puede variar en CI limpio.

## Reproducción / CI

```sh
bash tools/build-m36.sh --all
python -m pytest -c pytest.ini
bash tools/m3/check_style.sh
python tools/m36/visual.py --check
```

Workflow usa imagen SDK y acciones fijadas, sin red/dispositivos durante build,
y locks existentes para Python. Añade noveno perfil, prueba de app/política y
captura PNG. No añade paquetes. OCI/gateway ARM64/x86_64 y regresiones previas
siguen activos. El resultado GitHub debe comprobarse en el **HEAD exacto del PR**;
los resultados de M3.5 no se heredan. No se registra CI aprobada anticipadamente.
