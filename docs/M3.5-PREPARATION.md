## Hallazgos que condicionan la implementación

1. El snapshot v1 tiene cuatro contadores y dos alertas; no transporta catálogo
   multisitio, métricas completas de cada nodo ni ambiente local. El decoder C
   rechaza campos nuevos. La API rica requiere una evolución separada, no meter
   JSON adicional en v1 ni instalar un token reader en el ESP32.
2. GPIO42 no es el control de mute del amplificador: conecta PAVCC, compartida
   por audio y el participante I²C ES8311. El HAL ya necesita habilitarla durante
   lecturas RTC/SHTC3. GPIO46 controla el amplificador y hoy no lo maneja el HAL.
3. BOOT/GPIO0 es strapping y abre provisión durante el arranque M3 actual; PWR
   forma parte del circuito de batería. No convertir PWR en selector de vistas.
4. Leaf/CA/DNS y endpoint LAN8443 todavía requieren preflight/despliegue propios.
   La integración ASGI sintética no demuestra TLS físico ni conectividad Wi-Fi.

Para avanzar: preflight físico autorizado, después implementación incremental
en commits separados (API rica, firmware UI, perfiles de periféricos). Cualquier
carga/provisión y despliegue LAN requieren alcance y autorización específicos.
Consumo/autonomía, trabajo y cambios de red siguen pendientes.
