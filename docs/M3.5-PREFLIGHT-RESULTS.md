## Preservación

No se abrió serie ni se ejecutó esptool, read_flash/write_flash, reset,
aprovisionamiento o acceso NVS. No se modificaron eFuses, reloj RTC, seguridad,
bootloader/tabla, firmware o backup de fábrica. Los planes antiguos permanecen
consumidos y no se reutilizaron. El paquete nuevo no contiene una orden habilitada
de escritura/restauración. No se copió el backup completo a Git o al paquete público.

El archivo de fábrica mantiene modo 0644 dentro de su directorio propietario 0700,
que restringe acceso efectivo; se comprobó el hash y no se cambiaron sus permisos
para hacer pasar una validación artificial. Los datos detallados y ubicaciones
privadas permanecen fuera de Git; no se publican seriales, tokens o logs USB.
